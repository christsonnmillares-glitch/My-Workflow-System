# Executive VA Workflow Website

A professional, responsive single-page portfolio/workflow website for a Virtual Executive Assistant.

## Files
- `index.html` — website structure and content
- `styles.css` — responsive styling and workflow graphics
- `script.js` — smooth scrolling and subtle reveal animations

## Run locally
Open `index.html` in a browser.

## Publish on GitHub Pages
1. Create a new GitHub repository (for example: `executive-va-workflow`).
2. Upload `index.html`, `styles.css`, `script.js`, and this README.
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**.
5. Select `main` and `/ (root)`, then save.
6. GitHub will provide your public Pages URL.

No framework, build process, database, or server is required.
